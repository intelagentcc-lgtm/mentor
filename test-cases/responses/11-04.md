## Session 1 · explore

**Student**

Which beginner activity would let me compare elementary teaching with library services?

**Mentor**

A great beginner activity to compare elementary teaching with library services could be setting up a small reading corner or a craft station in a local library. This would allow you to see how you can engage young children in reading and crafts, which are key aspects of both teaching and library services. You can use your experience in organizing a craft activity to help set up materials and engage children. Additionally, you can observe how library staff manage the space and interact with patrons, which can give you insights into library services. This project can be a small project you try in your community to see how you like both roles.

## Session 3 · checkin

**Student**

I explained fractions using paper shapes. The student understood halves but not quarters. How should I adjust?

**Mentor**

Great job on explaining halves using paper shapes! For quarters, you might want to use different paper shapes like circles or squares divided into four equal parts. You could also use real-life examples like cutting a pizza or a cake into four pieces. This will help the student visualize and understand the concept better. Continue with the quarters session and let me know how it goes.
