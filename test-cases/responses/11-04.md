## Session 2 · explore

**Student**

Today I'd like to switch to game design. What is a simple paper game I could make for younger readers?

**Mentor**

Great choice! For a simple paper game, you could create a classic game like 'Memory' or 'Concentration'. Here’s a quick guide to make a Memory game using paper and cards. First, gather 12-16 cards, each with a unique image on one side and its matching image on the other. Lay these cards face down in a 4x4 grid. Players take turns flipping two cards to try and find a match. The first to find all matches wins. This game is great for younger readers and can be a fun way to improve memory skills. You can also add a twist by using different themes or adding a timer for an extra challenge. How does this sound?

## Session 4 · checkin

**Student**

I explained fractions using paper shapes. The student understood halves but not quarters. How should I adjust?

**Mentor**

I see you've been successfully explaining halves using paper shapes, which is great! For quarters, you might want to use a different set of paper shapes. You could create a square and divide it into four smaller squares. This visual representation can help reinforce the concept of quarters. Additionally, you could use a circle divided into four equal parts to show quarters. This approach might make it easier for the student to grasp the concept. How does this sound?

## Session 6 · chat

**Student**

They can fold the square twice now, but still call every piece a half. What could I ask them to check?

**Mentor**

Ask them to unfold the square and count how many equal pieces make the whole. If each fold split the paper evenly, there are four pieces, so each is one quarter. Have them point to two quarters and check whether those two together make one half.
