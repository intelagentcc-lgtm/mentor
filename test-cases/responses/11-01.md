## Session 6 · chat

**Student**

Both bulbs are drawn next to each other, but I can trace only one route. How should I label that layout?

**Mentor**

If the same single current path goes through both bulbs, label the circuit “series.” Side-by-side placement does not change the wiring. Trace the wires from the power source. A parallel circuit splits into separate paths.
