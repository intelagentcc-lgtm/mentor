## Session 7 · chat

**Student**

Help me compare two bulb diagrams, one with a single path and one with two branches.

**Mentor**

Great! Let's compare the two diagrams you drew. For the series circuit, you've already identified a single path for the current. Now, let's look at the parallel circuit. In a parallel circuit, the bulbs are connected in separate paths, meaning there are multiple routes for the current to flow. Here are the key components and connections to look for in each circuit:

**Series Circuit: (Single Path)**
- One path for the current to flow through both bulbs.
- Voltage is the same across both bulbs.
- Current splits at the junction but remains the same in each bulb.
- Resistance adds up in series.

**Parallel Circuit: (Multiple Paths)**
- Multiple paths for the current to flow, with each bulb having its own path.
- Voltage is the same across both bulbs.
- Current splits at the junction, with each bulb getting its own current.
- Resistance does not add up in parallel.

Can you identify these components in your diagrams and note how the current and voltage behave differently in each?

### Follow-up 1 · chat

**Student**

How can I check whether the wires share a single path even if the bulbs are drawn side by side?

**Mentor**

To check if wires share a single path even if the bulbs are drawn side by side, focus on the connections between the bulbs and the power source. In a series circuit, the bulbs are connected in a single path, so the wires will connect directly from the power source to each bulb and back to the power source. If the bulbs are drawn side by side but the wires are still connecting directly to each bulb and back to the power source, they are in a series circuit. If the wires are branching out to each bulb independently, then it's a parallel circuit. Let's apply this to the diagrams you drew. Can you identify where the wires are connecting directly to each bulb and back to the power source in the diagram with the bulbs side by side?
