## Session 2 · example

**Student**

Show a worked example of using Ohm's law with a 9 V source and a 3 ohm resistor.

**Mentor**

Sure, let's work through a simple example using Ohm's Law. Ohm's Law states that V = IR, where V is voltage, I is current, and R is resistance. Given a 9V source and a 3 ohm resistor, we can find the current flowing through the circuit. Here's how it looks:

V = IR
9V = I * 3 ohms
I = 9V / 3 ohms
I = 3 A

So, the current through the circuit is 3 Amperes.
