### Follow-up 1 · hint

**Student**

How should I set up the mean calculation? Just a hint, please.

**Mentor**

To calculate the mean of a set of sports scores, you first add up all the scores and then divide by the number of scores. For example, if you have the scores of a basketball game: 72, 85, 69, 91, and 78. Here’s how you set it up:

1. Add the scores: 72 + 85 + 69 + 91 + 78 = 395
2. Divide the total by the number of scores (which is 5 in this case): 395 ÷ 5 = 79.

So, the mean score is 79. Try calculating the mean for a different set of scores to practice. How would you calculate the mean of the scores 80, 75, 90, 85, and 78?

## Session 4 · explore

**Student**

What is an easy way to outline a short story in one afternoon?

**Mentor**

For your question about outlining a short story in one afternoon, here’s a simple outline structure you can use:

1. **Introduction** - Introduce the main character, setting, and a brief background. Aim for about 100-150 words.
2. **Inciting Incident** - This is the event that sets the story in motion. Keep it concise, about 100-150 words.
3. **Rising Action** - Describe the challenges and obstacles the main character faces. This part can be a bit longer, around 200-300 words.
4. **Climax** - The turning point of the story, where the main conflict reaches its peak. Aim for about 100-150 words.
5. **Falling Action** - After the climax, describe how the situation changes. This part can be shorter, around 100-200 words.
6. **Resolution** - Conclude the story, wrapping up the main conflict. This part can be about 100-150 words.

This structure should help you get started in one afternoon. If you need more detailed guidance, feel free to ask!
