## Session 3 · example

**Student**

Show a worked example of how to count a measure with two quarter notes and four eighth notes in 4/4.

**Mentor**

Assuming the notes are in the order listed, start each note on these counts: 1, 2, 3, and after 3, 4, and after 4. A quarter note lasts one beat. An eighth note lasts half a beat. They add up to four beats. Tap a steady “1 and 2 and 3 and 4 and” and clap only on the listed counts.

### Follow-up 1 · chat

**Student**

If the quarter notes come first, on which counts do the last four notes begin?

**Mentor**

If the quarter notes come first, the last four eighth notes would start on counts 5, 6, 7, and 8. Since each quarter note lasts one beat and each eighth note lasts half a beat, the eighth notes after the quarter notes would be on counts 5 and 6, and then 7 and 8. This is because the quarter notes would take up the first four beats (1, 2, 3, 4), and the eighth notes would fill the remaining four beats (5, 6, 7, 8).
